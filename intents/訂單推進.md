# 功能規格書 — 訂單推進

> 模組：訂單／動作：推進與退回
> 只講「推進與退回」這一個動作。狀態、原則、資料的定義都在[知識架構圖](架構圖.md)——這裡引用、不重抄。

## 這個動作在做什麼

訂單管到交付：`待處理` → `處理中` → `完成`，每步可退一格（照架構圖的退路規則：退也留紀錄；作廢只從 `待處理` 走，已開工的先退回再作廢）。狀態機照[架構圖・流程](架構圖.md)，不重畫。

## 行為

- 推進與退回各一鍵；每次都寫修改紀錄（誰、何時、從哪到哪）。
- `處理中`／`完成` 的畫面上沒有作廢鍵、API 也擋——要作廢先退回 `待處理`。

## 驗收

1. 待處理→處理中→完成，逐步推進各留一筆紀錄。
2. 完成點錯改回 → 回處理中＋紀錄；處理中退回 → 回待處理＋紀錄。
3. 處理中的訂單打作廢 API → 被擋，訊息指路「先退回待處理」。

## 施工順序

推進／退回 API（各帶狀態檢查）→ 驗收變測試 → 詳細頁按鈕。

## 對應實作

- API：`POST /api/v1/orders/{id}/start`、`/finish`、`/back`、`/reopen`；列表 `GET /api/v1/orders?status=&search=&page=&page_size=`
- 測試：`apps/lean-backend/apps/orders/tests_advance.py`——驗收 3 條
- 畫面：`apps/lean-admin/src/views/OrderListView.vue`、`OrderDetailView.vue`（表頭「開始處理／完成／退回待處理／點錯改回／作廢」）
