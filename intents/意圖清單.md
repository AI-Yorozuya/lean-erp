# 意圖清單：3C 店報價

> 意圖收斂交出的：AI 照五件事問，一次一題，問到你喊停，再整理成這張清單。

| 五件事 | 業務 |
|---|---|
| **誰在做** | 業務。做給公司客戶；客戶不進系統，全程由業務對外聯絡。 |
| **怎麼做** | 客戶來問價，業務確認品項、型號、數量；客戶和商品從既有資料裡選，不打字；查價目表帶入單價；算總額和免運；做成報價單。 |
| **交出什麼** | 報價單 PDF，傳給客戶。 |
| **有什麼特殊規則** | 小計滿十萬免運（剛好十萬也免運）；單價照價目表，不打折、不議價；不另外算稅。 |
| **什麼一定不能錯** | 報錯價：單價抓錯、免運算錯。報價單的總額一定等於品項加總。同名的商品要分得出型號。 |

實際上會問得更多，像老闆要看業績、人資要算獎金，也會各長一欄。這個範例到 3-2 才加老闆，那一欄先落在系統總覽，不回頭改這張清單。
