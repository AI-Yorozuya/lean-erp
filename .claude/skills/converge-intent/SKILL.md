# Converge Intent

把人腦中的散裝描述變成一份可共同校正的交接包。這是產品開發流程五站中的**前兩站（意圖、原型）**——知識架構圖、功能規格書都在閘門之後，不要取代它們。

> 本檔為交付副本（自足）；正本住 ai-yorozuya `jarvis/skills/converge-intent/`，改正本→同步這裡。

## 全景

**兩個迴圈、兩道閘門、一個袋**；人面顯示為四站（站＝迴圈的投影）：

| 站（人面） | 機器面 | 過門條件 | 過門產出（正名） |
|---|---|---|---|
| 1 聊想法 | 意圖迴圈（講 ⇄ 回述） | 四問每格過線＋他看卡點頭 | **意圖清單**（一張卡，之後不再長大） |
| 2 對流程 | 原型迴圈第一拍（推主流程） | 主流程每步確認「像」 | **主流程** |
| 3 點畫面 | 原型迴圈第二拍（點原型） | 物件連續兩輪不變＋結構題清零（依檔位） | **東西清單**＋袋收口 → 四件合訂＝**交接包** |
| 4 簽設計圖 | 架構站——**本 skill 之外**，出口路標 | — | 架構圖（下一站的事） |

「現在不做」袋全程收（隨口的以後想要、數值題、砍掉的訴求），閘門 2 收口。

## 開場（第一輪固定三動作）

1. **問強度**（表單一題）：速寫（練習／demo）／標準（自己的生意，**預設推薦**）／嚴格（收錢、簽約、上線）＋固定末項「這題怪怪的」。
2. **報整場的形**：「整場三站：聊想法（通常 2–4 輪）→ 對流程 → 點畫面（通常 2–3 輪），最後交給設計圖。你隨時可以喊停。」
3. **請他開講**：想到什麼講什麼——口述、逐字稿、會議記錄、雜訊筆記都收。

## 互動規則（每一輪都適用）

- 每輪固定形：**儀表行 → 回述 → 至多一問**。使用者回了才算下一輪；不准一次倒完所有問題、不准悶頭產長文。
- **有結構化提問工具（如 AskUserQuestion）就用表單**：每題最多 4 個選項、可複選用 multiSelect；**固定末兩項＝「換個問法」＋「這題怪怪的」**——換個問法＝題目沒壞但他想聽別種說法或沒聽懂（換個角度重問，不登記）；怪怪的＝題目本身有病（走爛題登記）。扣掉末兩項，實質選項每題最多 2 個，不夠就拆成多題並列。**進度行放進表單前導文**（使用者盯的是表單，表單外的進度等於沒有）。沒有工具→文字編號選項。
- **確認也是題**：卡片點頭、過門、總確認一律用表單（「都對，過門」／「有要改的」＋固定末兩項），不出開放式「點頭嗎」「哪裡不對」散文——選了「有要改的」才逐項問。
- **回答成本上限＝挑一個**：每題都要能用選項或點頭答完。要他去數、去翻、去寫的題不出——那筆資料之後從系統資料自己算，或降級成「重要／不重要」判斷題。
- 決策題附 2–4 個候選、各帶代價（解什麼＋傷什麼）、必含「先不決定」（入袋）。不出裸問句；**不准叫使用者自己拆塊**——拆塊是你的工作，他只負責挑或改。
- **先意圖，後方案**：聽到「我要一個 XX」→「要它是為了什麼？」，追到答案出現決定或後果就停。
- **事實題六關**（出手前逐關過）：①回答成本上限＝挑一個②一題一事件、一個時間尺度（跟進＝天週、回查＝月年，拆開問）③先過濾再深挖（「有沒有發生過X？」——「沒有」也是黃金答案）④問那件事的三要素（情境／做了什麼／後果），不問「隔多久」「多常」⑤能選就不問開放題⑥「為什麼」至多追兩層（答案滑到理念＝到頂，收線）。
- **對自建者不出「證明你的痛」的功課題**——錨定用寄生的：他主動講到的真事直接收錨；看流程時順口邀他對照最近一件真事（零成本邀請，不是作業）。
- **「這題怪怪的」被選＝題目有病**：原題不追問 → 自診破了哪關 → 換問法或跳過（跳過合法）→ 記一行進本資料夾 `爛題登記.md`（日期／原題／破哪關／改成什麼）。**出題前先讀登記簿，同型錯不再犯。**
- 🔴 分流：**結構性**（答案會改變核心物件、主流程或責任線）才佔問題名額；數值性直接入袋，回述一行帶過。**開關比**：本輪關掉的題 < 新開的題 → 下輪禁提新問，先出收斂稿釘住已知。**回述遞減**：只列本輪新增與變更，一輪比一輪短。
- **🔴 行內嵌**：已有草稿／流程稿時，🔴 除了列清單也就地嵌 `[🔴: 具體問題]` 在缺口位置，回填時兩處一起銷。
- 目的相撞 → 收斂成「哪個先讓步」的單選；中途新增目的 → 先明列翻掉哪些結論，逐條改、不重來；讓步方進袋。

## 儀表（兩面）

- **機器面**（AI 每輪內部記錄、判過門用，不上桌）：意圖迴圈＝格 x/4・🔴剩 z 結構・新項率；原型迴圈＝流程 k/n 步像・Δ物件・🔴剩 z（w 數值入袋）・穩定 s/2 輪。
- **人面**（唯一顯示）＝兩行：第一行**站名頭**`【第 2/4 站・對流程】4/6 步——還缺哪些、下一步`（站名＋第幾站/共幾站＋站內細數＋一句話）；第二行**路線圖**`聊想法 ✓ → 對流程 4/6 → 點畫面 → 簽設計圖`。表單前導文空間有限時只放第一行。
- 規則：**進行中那站顯示站內細數，完成的站打 ✓**——每站用自己的**可知分母**：聊想法＝x/4（四問格數）；對流程＝k/n（主流程步數，圖出來就known）；點畫面＝「剩 z 題」（結構題封口後報實數，之前只計「第 n 輪」）。範例：`進度：聊想法 ✓ → 對流程 4/6 → 點畫面 → 簽設計圖`。**分母只准用可知的數**；輪數、問題總數禁當分母；**格／錨／🔴／Δ／檔等內部詞禁止上桌**；**禁報「完成 xx%」**。儀表每一輪都要有變化——連兩輪數字全同＝發散警訊，自查。
- 機器面已趨零又跳動＝警訊：回頭查，不硬停。

## 強度三檔（開場設定、中途可換）

| | 速寫 | 標準（預設） | 嚴格 |
|---|---|---|---|
| 四問 | 有字即可 | 每格過線 | 每格過線 |
| 錨定 | 免 | 寄生（流程對照真實案例） | 每格明確錨定（對外訪談／接案用） |
| 飽和 | 免 | 新項率連續 2 輪 ≤5% | 連續 3 輪 0 新項 |
| 穩定 | Δ=0 × 1 輪 | Δ=0 × 2 輪 | Δ=0 × 2 輪＋每條原則附反例 |
| 結構性 🔴 | 可入袋帶走 | 清零 | 清零＋決策留痕 |

換檔：**升檔 → 立刻列缺口清單**；**降檔 → 記一筆進袋**（誰決定的、為什麼）。

## 站 1 聊想法（意圖迴圈）

對照**意圖四問**萃取，缺的留白＝🔴，不猜：

1. **給誰用？**——過線＝說得出誰會開、誰會看（角色即可，不用 persona）。
2. **用來做什麼？**——過線＝有動詞、有對象。
3. **做完會得到什麼？**——答**利益**不答產出物規格；答案出現名詞（表／頁／報表）→ 追問「有了它你會怎樣」，到出現動詞或後果為止。
4. **什麼絕對不能發生？**——過線＝判得出有沒有發生、寫得成測試（它會長成不變量與驗收）；感受型願望（「不能得罪客人」）不算，答不出留白進 🔴。

**類比錨起手**（可選）：「這像你現有的哪個流程、或別人家的哪個東西？」——一個類比帶出一串物件×動作；答不出就放掉。

**閘門 1**＝每格過線＋他看卡點頭（哪格不對就改，改到點頭；不要求複述——不考客人）。過門亮出**意圖清單**卡。

## 站 2 對流程（原型迴圈第一拍）

從意圖清單推一條主流程 `起點 → 動作 → 可見結果`，用表格呈現（每步：他做什麼／他看到什麼）。

- 確認＝**複選表單**：每步一個勾選項（勾「不像」的）＋「這幾步都像」＋「這題怪怪的」；步驟多就分組成多題。勾了哪步，只追問那一步。
- **寄生錨定**（零成本邀請）：「順手拿最近真的一件，在腦中照著走——哪步不像點出來就好。」
- **排序（先做哪塊）在這站問**：主流程出來才有塊可指。**由你提案**哪幾步是主幹、哪幾步可進「現在不做」，附代價，他點頭或改。

過門亮出**主流程**。

## 站 3 點畫面（原型迴圈第二拍）

- 把主流程做成**能點的操作畫面原型**：單檔 HTML＋假資料、無後端；有 preview 就開給他點，點不了的環境退化成逐屏文字稿確認。能點即可，不精修 UI。
- 收出**不可猜的核心物件×動作**。點名不解答：「怎麼存」是資料表分水嶺的只點名、帶進架構站（警戒線：多數小系統 3–7 個物件，明顯更多先檢查是不是把欄位當成物）。不展開欄位、計算、權限、完整狀態機。
- 清結構題（表單／候選形式）；數值題入袋。
- **閘門 2**（依檔位）＝主流程走得完＋核心物件連續兩輪不變＋結構性 🔴 清零（只剩數值）。**由你主動宣告**，他可否決，否決＝續圈。

## 交接（過閘門 2）

三種結果：**未收斂**（保留 GAP 續圈）／**可進架構站**（交接包→知識架構圖；從零系統可接 `intent-to-rules`）／**可進製作**（交對應領域流程，附回溯本包的成功條件與底線）。

**交接包＝四件合訂**（每件＝知識架構圖某一層的種子）：①意圖清單（→目的與原則）②主流程（→流程層）③核心物件×動作清單（→資料層）④「現在不做」清單——分三小節：待確認／先不決定／本次不做＋一句為什麼（→動工前要決定的問題＋範圍界線）。原型＝頁面層**參考**，規格從架構圖長。**整包叫交接包，不准叫意圖清單。**

**lean-stack 系 repo：把交接包寫成 `intents/交接包.md`，然後交還 `/next` 進架構站。** 其他環境預設對話輸出。

## 輸出模板

每輪回述：

```markdown
【第 1/4 站・聊想法】2/4 格——還缺「做完會得到什麼」「絕不能發生什麼」，預計再 ~2 輪
聊想法 2/4 → 對流程 → 點畫面 → 簽設計圖

## 這一輪
- 🟢 新增／變更：（只列本輪）
- 🟡 建議：（附代價：解什麼＋傷什麼）
- 🔴 還不知道：（只列結構性；另 N 條數值已入袋）

**本輪只回這題** →（表單，或 2–4 個候選各帶代價、含「先不決定」）
```

意圖清單（閘門 1 過門時）：

```markdown
# 意圖清單
- **給誰用**：…
- **用來做什麼**：…
- **做完會得到什麼**：…
- **絕不能發生**：…

（接確認表單：都對，過門／有要改的／換個問法／這題怪怪的）
```

交接包（閘門 2 過門時）：四件各一段、每段不超過五行。
